# SWAFIX Website & Tech Platform ⚡

Welkom bij de officiële bronbestanden van de **SWAFIX** website.

## 🚀 Inbegrepen Bestanden & Structuur

- [`index.html`](file:///Users/Apple/swafix/index.html): De hoofdstructuur van de website met SEO-best practices, responsieve secties, interactieve prijsberekener, live reparatietracker, FAQ en afspraak-modal.
- [`css/style.css`](file:///Users/Apple/swafix/css/style.css): Modern Glassmorphism design system met custom CSS variabelen, donker/licht thema ondersteuning, animaties en responsive grid layouts.
- [`js/main.js`](file:///Users/Apple/swafix/js/main.js): Dynamische JavaScript logica voor directe prijsberekeningen, reparatiestatus opzoeken, thema-schakelaar, pop-up modal en accordeons.
- [`assets/`](file:///Users/Apple/swafix/assets/): Logo (`logo.jpg`), hero banner (`hero.jpg`) en smart home afbeeldingen (`smarthome.jpg`).
- [`package.json`](file:///Users/Apple/swafix/package.json): NPM configuratie om de site direct te starten met een lokale dev server.

## 💻 Hoe lokaal uitvoeren?

Open de terminal in de projectmap `/Users/Apple/swafix` en voer uit:

```bash
npm start
```

Of open eenvoudig [`index.html`](file:///Users/Apple/swafix/index.html) in een willekeurige webbrowser.
